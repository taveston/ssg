17 · Missiles in flight

A · Arrow (current) · colour and greyscale

B · Small affiliation shape + velocity leader · colour and greyscale

B in use · a salvo from launch to the end

A: own and hostile arrows differ only by colour, so in greyscale (or for some colour-blind players) they are the same mark. B: the shape carries affiliation as the ship frames do (own circle, hostile diamond, unknown quatrefoil), small, solid and without an icon, so a missile never reads as a ship. Direction comes from the velocity leader, which grows with speed (SYM-11). A salvo stays one mark: its missiles are within a few km of each other, the same pixel at any useful zoom. Its count drops as missiles are shot down (a burst per kill) or decoyed; a decoyed missile gets its own mark only if its path visibly diverges. Described in combat-view.md 3.
