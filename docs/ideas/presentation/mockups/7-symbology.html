Ship symbology

CANDIDATE Adapted from NATO APP-6 / MIL-STD-2525: frame shape = affiliation, icon = what it is, amplifiers around the frame = state. Corvane system, 14 Mar 2341.

Frames × icons

Shape carries affiliation even without colour. Filled icon = armed; outline icon = unarmed.

Amplifiers

Added around the frame, never inside it, so the core symbol always reads the same.

Identification ladder

A contact firms up as tracking improves. Each step adds to the symbol rather than replacing it.

In context: near Halden IV

Task force TF-1 escorting convoy C-12 inbound, a replenishment tanker on station, an embarked battalion heading for Port Arden, a neutral trader, a hostile raider and an unidentified track.

Size on screen

Today's markers are about 14 px. A framed symbol needs about 22 px for the icon to read; groups and data blocks add width.
